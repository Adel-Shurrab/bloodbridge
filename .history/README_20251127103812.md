# 🩸 BloodBridge – Intelligent Blood Donation Management System  
*A Graduation Project – Computer Systems Engineering, 2024/2025*

BloodBridge is an intelligent, secure, and centralized **Blood Donation Management System (BDMS)** designed to modernize and streamline the blood donation lifecycle.  
The system connects **donors**, **healthcare organizations**, and **administrators** through real-time communication, smart matching, geolocation-based targeting, and automated workflows.

This project was developed to address the urgent need for faster donor mobilization and improved coordination in regions with limited medical resources, such as the Gaza Strip.

---

## 🚀 Features at a Glance

### 🧭 **Location-Based Search**
- Interactive map for locating nearby donors and donation centers.  
- Geofencing to alert only donors within a practical distance.

### 🚨 **Real-Time Emergency Notifications**
- Multi-channel alerts (SMS, Email, Push).
- Fast broadcasting to eligible donors within seconds.

### 🤖 **Smart Matching Engine**
- AI-powered selection of the most suitable donors based on:  
  - Blood type compatibility  
  - Geographical radius  
  - Donation history  
  - Availability (90-day rule)  
  - Health profile  

### 📅 **Appointment Scheduling**
- Donors can book or cancel appointments.
- Healthcare organizations manage daily capacity and scheduling.

### 🏆 **Gamification System**
- Points, levels, and badges to motivate continuous donor engagement.
- Leaderboards and milestones.

### 🔐 **QR-Based Donation Verification**
- Time-limited, single-use QR codes scanned by healthcare staff.
- Secure confirmation of completed donations.

### 📊 **Advanced Analytics Dashboard**
- KPIs, charts, heatmaps, and real-time statistics.
- Admin-level insights for planning and monitoring.

### 🛡️ **Privacy & Security by Design**
- RBAC, encrypted data, audit logs, and strict access control.
- Donor anonymity preserved until acceptance.

## 👥 System Users

### 📝 **1. Visitor**
- View landing page, statistics, and information.
- Register as a donor or healthcare organization.

### 🩸 **2. Donor**
- Complete medical & personal profile.
- Receive urgent blood requests.
- Accept/decline requests with one click.
- View donation history and next eligible date.
- Earn points and badges.

### 🏥 **3. Healthcare Organization**
- Create and manage blood requests.
- Track matched/accepted donors.
- Manage appointments and verify donations via QR.
- Access dashboards and reports.

### 🛠️ **4. Administrator**
- Approve/reject organization registrations.
- Monitor system activity & security logs.
- Generate system-wide reports (PDF/Excel).
- Manage users, permissions, and alerts.

## 🧱 System Architecture

### **Tech Stack**
| Layer | Technology |
|-------|------------|
| Frontend | Blade, Tailwind, JS |
| Backend | Laravel Framework (PHP) |
| Database | MySQL + (optional) Firebase RTDB |
| Real-Time Updates | Laravel Echo + Pusher |
| Maps | Google Maps API |
| Notifications | Twilio (SMS), Email, Push |
| Authentication | Laravel Breeze + 2FA |

### **Architecture Style**
- Modular three-tier architecture  
- RESTful APIs  
- WebSockets for real-time alerts  
- Queues for heavy/broadcast tasks  
- Privacy-first implementation

## 🧪 Functional Highlights

### Blood Requests Workflow
1. Organization creates a request.  
2. Smart matching engine selects eligible donors.  
3. Real-time alerts sent instantly.  
4. Donors accept/decline.  
5. Organization tracks incoming donors.  
6. Donation verified via QR.  
7. Donor eligibility updated (90-day rule).
